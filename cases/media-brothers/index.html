Media Brothers

#digitalmarketing#webdesign#uxuidesign

A bold, content-led website for a digital marketing agency

#about

Media Brothers is a digital marketing agency helping businesses grow through SEO, paid search advertising, and analytics
The project was to create a multi-page website from scratch and give the agency’s services a clear, distinctive presentation

#the challenge

The agency needed a bold website without relying on heavy images, animation, or video
With little existing copy and few visual assets, the challenge was to make text-heavy pages engaging while keeping them easy to scan

Each page also needed to answer a specific visitor question and make the next step clear
The first screen was designed to occupy around 70–75% of the viewport, leaving 20–25% of the next section visible to invite visitors to scroll

#the approach

The project followed 7 stages:

  1. Audience research
  2. Competitor analysis
  3. Functional prototyping
  4. Reference research
  5. Visual concept development
  6. Tablet and mobile adaptation
  7. UI kit creation

#the solution

  • Used custom graphic elements to add visual interest without image-heavy pages, animation, or video
  • Introduced several accent colors to create a bold visual identity and distinguish key sections
  • Reworked draft copy into concise, scannable content, breaking up long text blocks
  • Structured pages around visitor questions and clear actions
  • Designed layouts for desktop, tablet, and mobile
  • Kept the first screen compact, with part of the next section visible below it

#deliverables

  • Multi-page website design
  • Functional prototype
  • Desktop, tablet, and mobile layouts
  • UI kit
  • Website copy developed from initial placeholder text

#results

The finished design brings Media Brothers’ three core service areas—SEO, paid search advertising, and analytics—into a clear, content-led website
Custom graphics and a bright accent palette give the text-heavy pages a distinctive character without relying on heavy media

Conversion increased from 2% to 8% (+6 percentage points)
